# Security policy for [Nmbrz](../README.md) package

## Supported Versions

| Version  | Supported                   |
| -------  | --------------------------- |
| >1.0     | ✅ full support              |
| >=0.2    | supported with solved issues |
| 0.1      | ⛔ not recomented            |
